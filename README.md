
# IRONHEX

A robust, secure application designed to eliminate fragmented and insecure manual storage of sensitive data. This tool acts as an encrypted digital vault, providing a structured way to manage your confidential information.

 


## Features

- CRUD operations on database
- Search items based on name
- Secure vault for storing private information
- Used AES and Argon2id algorithms
- Generate new passwords easily


## Installation

Open project with Intellij IDEA and build artifact, for preventing signature errors when running software, don't create "far jar", put dependency outside of main jar file.
    
## Deployment

To run software run this command

```bash
  java -jar ironhex2.jar
```

if you get jni warning you can disable it using this command

```bash
  java -jar --enable-native-access=ALL-UNNAMED ironhex_2.0.jar
```
